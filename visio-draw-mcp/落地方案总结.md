# Visio Draw MCP 落地方案总结

## 项目概述

已成功实现基于 MCP (Model Context Protocol) 的 Visio 自动绘图服务器，让 Claude Code 能够通过自然语言自动生成 Visio 图表。

```

    ├── architecture.json      # 系统架构图示例
    └── network_topology.json  # 网络拓扑图示例
```

## 核心功能

### 1. MCP 工具（5 个）

| 工具名称 | 功能描述 | 参数 |
|---------|---------|------|
| `list_available_stencils` | 列出可用的图标库文件 | 无 |
| `list_stencil_masters` | 列出图标库中的所有图标 | stencil: 图标库文件名 |
| `validate_diagram_spec` | 验证图表规格是否合法 | spec: DiagramSpec 对象 |
| `draw_visio_diagram` | 生成 Visio 图表 | spec: DiagramSpec 对象 |
| `export_visio_diagram` | 导出为 PNG/PDF | input_file, format |

### 2. 数据结构

**DiagramSpec** - 图表规格：
- `title`: 图表标题
- `stencil`: 图标库文件名
- `nodes`: 节点列表（NodeSpec）
- `edges`: 边列表（EdgeSpec）
- `layout`: 布局配置（LayoutSpec）
- `output_name`: 输出文件名

**NodeSpec** - 节点规格：
- `id`: 唯一标识
- `label`: 显示文本
- `master`: 图标名称
- `x`, `y`: 可选坐标

**EdgeSpec** - 边规格：
- `from`: 起点节点 ID
- `to`: 终点节点 ID
- `label`: 连接线文本

### 3. 布局选项

- `LR`: 从左到右（默认）
- `TB`: 从上到下
- `GRID`: 网格布局（4 列）

### 4. 安全特性

- ✅ 路径安全验证（限制在项目目录内）
- ✅ 文件名清理（防止路径遍历）
- ✅ 规模限制（最大 100 节点，300 边）
- ✅ 自动生成唯一文件名（避免覆盖）
- ✅ 输入验证（Pydantic）

## 技术实现

### 1. MCP 服务器（server.py）

使用 FastMCP 框架：
```python
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("visio-draw-mcp")

@mcp.tool()
def list_available_stencils() -> dict:
    return list_stencils()

if __name__ == "__main__":
    mcp.run()
```

### 2. Visio COM 自动化（visio_driver.py）

使用 pywin32 调用 Visio COM 接口：
```python
import win32com.client as win32

visio = win32.gencache.EnsureDispatch("Visio.Application")
visio.Visible = False

# 打开图标库
stencil_doc = visio.Documents.OpenEx(
    str(stencil_path),
    constants.visOpenRO | constants.visOpenHidden
)

# 放置图标
master = stencil_doc.Masters.ItemU(master_name)
shape = page.Drop(master, x, y)
shape.Text = label

# 连接节点
source_shape.AutoConnect(target_shape, 0)
```

### 3. 数据验证（schema.py）

使用 Pydantic 进行数据验证：
```python
from pydantic import BaseModel, Field

class NodeSpec(BaseModel):
    id: str = Field(..., description="节点唯一 ID")
    label: str = Field(..., description="节点显示文本")
    master: str = Field(..., description="Master 名称")
```

### 4. 安全控制（visio_driver.py）

路径安全验证：
```python
def _resolve_stencil_path(stencil: str) -> Path:
    path = (STENCIL_DIR / stencil).resolve()
    
    # 确保路径在 stencils 目录内
    if not str(path).startswith(str(STENCIL_DIR.resolve())):
        raise ValueError("Invalid stencil path")
    
    return path
```

## 常见问题

### Q1: MCP 服务器无法启动

**解决方案**:
1. 检查 Python 是否在 PATH 中
2. 确保所有依赖已安装
3. 手动运行 `python server.py` 查看错误

### Q2: Visio COM 不可用

**解决方案**:
1. 确保已安装 Microsoft Visio
2. 尝试手动启动 Visio 一次
3. 重新安装 pywin32

### Q3: Master 图标找不到

**解决方案**:
1. 使用 `list_stencil_masters` 查看实际可用的图标
2. 注意 Master 名称区分大小写
3. 确保使用正确的图标库文件
